Всем доброго времени суток, в этом “видео” попробуем разобраться как общаются между собой Z80 и “VDAC 2”.

Введение

Как уже упоминалось, обмен информацией происходит по одноканальному интерфейсу SPI. Не буду вдаваться в глубокие подробности работы, в интернете полно информации объясняющие работу этого протокола передачи данных. В нашем случае нужно лишь понимать что работа с графическим контроллером FT812  осуществляется, через него. Упомяну парочку особенностей работы с устройством, во-первых, каждая транзакция начинается с подачи сигнал выборки CS, и заканчивается снятием сигнал выборки. Во-вторых, осуществить саму передачу данных, длина одной транзакции, не ограничена, если адрес памяти является непрерывным. 

Из документации портов “TS-Config”, касательно работы с “VDAC 2” нас интересуют следующие:

STATUS (0xAF) [2..0] Read - его первые три бита, отвечающие за версию видеоадаптера. Нас интересует последний.

000 - 2-bit VDAC + PWM levels 0-24;
001 - 3-bit VDAC;
010 - 4-bit VDAC;
011 - 5-bit VDAC;
111 - VDAC2 (FT812).

VCONFIG (0xAF) 

- [2] Write - его второй бит, название бита FT_EN

0 - выбран вывод через стандартный видеоадаптер “TS-Config”;
1 - выбран вывод через FT812.

- [5] Write - его пятый бит, название бита NO_GFX
0 - включен простой графический контроллер, отображаются пиксели
1 - обычный графический контроллер отключен, пиксели не отображаются

DMA имеет низкий приоритет, из за этого она получает разное количество циклов на передачу данных. Лимит одной строки 448 циклов, которые тратятся на отображение стандартно экрана спектрума и  CPU остальные циклы отходят DMA, зная это, можно пренебречь  стандартным экраном спектрума, отключив чтение данных из ОЗУ при отрисовки экрана, что позволит сохранить эти циклы на передача данных через DMA и работу с CPU. Также, нужно понимать что на верхнем/нижнем бордюре, не происходит чтение данных из ОЗУ для отрисовки, ибо нет графики, что дает больше свободных циклов. 


SPI_CTRL (0x77) Write - необходим для выборки сигналов CS устройств, работающие через интерфейс SPI, нас интересует два состояния:

SPI_FT_CS_OFF (0x03)
SPI_FT_CS_ON  (0x07)

0 бит - для ZX-Evolution, не имеет значение
1 бит - работа с SD картой	(0 - enable, 1 - disable)
2 бит - работа с FT812	(0 - disable, 1 - enable)

SPI_DATA (0x57) Read/Write - непосредственно порт обмена данными между Z80 и FT812


Также обмен данными можно осуществить, используя DMA, но об этом поговорим чуть позже.

 ; Включение FT812 для работы с ним через интерфейс SPI
 FT_ON	macro
 	LD A, SPI_FT_CS_ON	; в регистре значение для включения FT812
 	OUT (SPI_CTRL), A		; отправка значения в управляющий порт SPI
  		endm

 ; Выключение работы с FT812 через интерфейс SPI
 FT_OFF	macro
 	LD A, SPI_FT_CS_OFF	; в регистре значение для включения FT812
 	OUT (SPI_CTRL), A		; отправка значения в управляющий порт SPI
	endm

 ; Переключение вывода изображения через FT812
 FT_VMODE 	macro
 	LD A, VID_FT812		; в регистре значение - тип вывода
  	OUT (VCONFIG), A		; отправка значения в порт видео конфигурации
 	endm












Чтение данных из FT812

Для операции чтения памяти из FT81, процессор Z80 отправляет два нулевых бита, за которыми следует 22-битный адрес. За которым следует фиктивный байт, для того чтобы  FT812 подготовил данные. После фиктивного байта FT812  начинает передавать данные, выставляя байт данных после каждого считанного байта данных. Напомню, что в областью памяти может быть как общая память (RAM_G), список команд (RAM_DL), регистровая память (RAM_REG), память кольцевого буфера со-процессора (RAM_CMD) и т.д.
[IMG embed=rId13]


; ------------------------------------------------------------
; Чтение 8 бит информации из регистра указанного в DE
; In :
;    DE - младшие 16 бит адреса регистра [15..0]
; Out :
;    A - прочитанное значение
; Corrupt :
;	    AF
; ------------------------------------------------------------
FT_RD8:	FT_ON				; включение SPI FT812
 			LD A, FT_RAM_REG >> 16	; старший адрес регистровой памяти[21..16]
 			OUT (SPI_DATA), A		; отправка адреса [21..16]
 			LD A, D
 			OUT (SPI_DATA), A		; отправка адреса [15..8]
 			LD A, E
 			OUT (SPI_DATA), A		; отправка адреса [7..0]
   		OUT (SPI_DATA), A 	; отправка фиктивного байта
 			IN A, (SPI_DATA)       ; чтение фиктивного байта (особенность
 							; работы с контроллером)
 			IN A, (SPI_DATA)		; чтение данных из указанного регистра
 			PUSH AF			; сохранение результат
 			FT_OFF			; отключение SPI FT812
 			POP AF			; восстановление результата
 			RET

; ------------------------------------------------------------
; Чтение 16 бит информации из регистра указанного в DE
; In :
;    DE - младшие 16 бит адреса регистра [15..0]
; Out :
;    BC - прочитанное значение
; Corrupt :
;	    BC, AF
; ------------------------------------------------------------
FT_RD16:	FT_ON				; включение SPI FT812
 			LD A, FT_RAM_REG >> 16	; старший адрес регистровой памяти[21..16]
 			OUT (SPI_DATA), A		; отправка адреса [21..16]
 			LD A, D
 			OUT (SPI_DATA), A		; отправка адреса [15..8]
 			LD A, E
 			OUT (SPI_DATA), A		; отправка адреса [7..0]
   		OUT (SPI_DATA), A 	; отправка фиктивного байта
 			IN A, (SPI_DATA)       ; чтение фиктивного байта (особенность
 							; работы с контроллером)
 			IN A, (SPI_DATA)		; чтение младшего байта данных
 			LD C, A
 			IN A, (SPI_DATA)		; чтение старшего байта данных
 			LD B, A
 			FT_OFF			; отключение SPI FT812
  		RET



Методы FT_RD8 и FT_RD16, предназначены для чтения значений их адресного пространства регистровой памяти (0x302000 - 0x302FFF), по этому старший байт адреса  регистровой памяти указан в методе явно (FT_RAM_REG >> 16 = 0x30). Со всеми адресами регистров, познакомимся позже.


; ------------------------------------------------------------
; Чтение данных из памяти FT812
; In :
;    HL  - адрес памяти (адресное пространство Z80	: 0x0000 - 0xFFFF)
;    ADE - адрес памяти (адресное пространство FT812	: 0x000000 - 0x308FFF)
;    BC  - количество байт
; Corrupt :
;	    BC, AF
; ------------------------------------------------------------
FT_Read:	PUSH AF			; сохранение аккумулятора
 			FT_ON				; включение SPI FT812
 			POP AF			; восстановление аккумулятора
 			OUT (SPI_DATA), A		; отправка адреса [21..16]
 			LD A, D
 			OUT (SPI_DATA), A		; отправка адреса [15..8]
 			LD A, E
 			OUT (SPI_DATA), A		; отправка адреса [7..0]
 			OUT (SPI_DATA), A    	; отправка фиктивного байта
 			IN A, (SPI_DATA)     	; чтение фиктивного байта (особенность
 							; работы с контроллером)
 			LD A, B			; аккумулятор, выполняет роль хранения
							; количества пакетов по 256 байт
 			LD B, C			; рег. B, хранит количество считываемых байт
 			LD C, SPI_DATA		; рег. C, указывает на порт SPI данных
			; цикл чтения
.Loop		INIR				; считать из порта SPI, количество байт,
							; указанное в рег. B
 			OR A				; проверка, аккумулятора на ноль
 			JR Z, .Exit			; выход, если в аккумуляторе ноль
 			DEC A				; уменьшим аккумулятор на единицу, 
							; в рег. B ноль, позволит получить 256 байт
 			JR .Loop			; продолжим получение данных
			; завершение работы
.Exit		FT_OFF			; отключение SPI FT812
 			RET

































Запись данных в FT812


Для операции записи в память FT812, процессор Z80 отправляет бит «1» и «0», за которым следует 22-битный адрес. Далее следуют записываемые данные.


[IMG embed=rId14]

; ------------------------------------------------------------
; Запись 8 бит информации в регистр указанный в DE
; In :
;    DE - младшие 16 бит адреса регистра [15..0]
; Out :
;    A - записываемое значение
; Corrupt :
;    AF
; ------------------------------------------------------------
FT_WR8:	PUSH AF					; сохранение аккумулятора
  			FT_ON						; включение SPI FT812
 			LD A, (FT_RAM_REG >> 16) | 0x80	; старший адрес регистровой
									; памяти[21..16], включим старший
									; бит, сигнализирующий об
									; операции записи в память FT812
 			OUT (SPI_DATA), A				; отправка адреса [21..16]
 			LD A, D
 			OUT (SPI_DATA), A				; отправка адреса [15..8]
 			LD A, E
 			OUT (SPI_DATA), A				; отправка адреса [7..0]
 			POP AF					; восстановление аккумулятора
 			OUT (SPI_DATA), A				; отправка записываемого значения
 			FT_OFF					; отключение SPI FT812
 			RET





; ------------------------------------------------------------
; Запись 16 бит информации в регистр указанный в DE
; In :
;    DE - младшие 16 бит адреса регистра [15..0]
; Out :
;    BC - записываемое значение
; Corrupt :
;	    BC, AF
; ------------------------------------------------------------
FT_WR16:	FT_ON						; включение SPI FT812
 			LD A, (FT_RAM_REG >> 16) | 0x80	; старший адрес регистровой
									; памяти[21..16], включим старший
									; бит, сигнализирующий об
									; операции записи в память FT812
 			OUT (SPI_DATA), A				; отправка адреса [21..16]
 			LD A, D
 			OUT (SPI_DATA), A				; отправка адреса [15..8]
 			LD A, E
 			OUT (SPI_DATA), A				; отправка адреса [7..0]
 			LD A, C
 			OUT (SPI_DATA), A				; отправка младшего байта значения
 			LD A, B
 			OUT (SPI_DATA), A				; отправка старшего байта значения
 			FT_OFF					; отключение SPI FT812
 			RET





; ------------------------------------------------------------
; Запись данных в память FT812
; In :
;    HL  - адрес памяти (адресное пространство Z80	: 0x0000 - 0xFFFF)
;    ADE - адрес памяти (адресное пространство FT812	: 0x000000 - 0x308FFF)
;    BC  - количество байт
; Out:
;    HL  - адрес + количество байт
;    ADE - адрес памяти FT812 + количество байт
; Corrupt :
;	    HL, DE, BC, AF
; ------------------------------------------------------------
FT_Write:	PUSH AF 
 			FT_ON				; включение SPI FT812
 			POP AF
 			PUSH AF
 			OR #80			; включим старший бит, сигнализирующий об
							; операции записи в память FT812

 			OUT (SPI_DATA), A		; отправка адреса [21..16]
 			LD A, D
 			OUT (SPI_DATA), A		; отправка адреса [15..8]
 			LD A, E
 			OUT (SPI_DATA), A		; отправка адреса [7..0]
 			POP AF

			; рассчитаем адреса памяти, для следующего блока
 			EX DE, HL
 			ADD HL, BC			; HL  += BC
 			EX DE, HL
 			ADC A, #00			; ADE += BC
 			PUSH AF

			; подготовка отправки пакета данных
 			LD A, C			; в аккумуляторе, младший байт 
 							; количества передаваемых данных 
 			OR A				; проверим его на ноль
 			LD A, B			; теперь аккумулятор хранит старший байт
							; количества передаваемых данных
 			LD B, C			; рег. B, хранит количество передаваемых байт
 			LD C, SPI_DATA		; рег. C, указывает на порт SPI данных
 			JR Z, .Loop			; перейдём, если количество передаваемых
							; данных выровнено 256 байтам

			; отправка данных, если количество меньше 256
 			OTIR
 			OR A				; проверим, есть ли что отправлять?
 			JR Z, .Exit			; выход, если количество отправляемых данных
							; равно нулю

			; основной цикл отправки данных
.Loop		OTIR
 			DEC A				; уменьшим аккумулятор на единицу, 
							; в рег. B ноль, позволит отправить 256 байт
 			JR NZ, .Loop		; продолжим отправку данных, если в
							; аккумуляторе не ноль
.Exit		FT_OFF			; отключение SPI FT812
 			POP AF
 			RET








Команды управлением FT812 (системные)

При отправке команды управления, процессор Z80  отправляет бит «0» и бит «1», за которыми следует 6-битный код команды. Второй байт может быть либо 0х00, либо аргументом этой команды. Третий байт всегда 0х00.
