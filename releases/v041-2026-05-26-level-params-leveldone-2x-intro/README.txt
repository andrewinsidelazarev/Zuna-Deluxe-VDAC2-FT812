Zuma Deluxe — VDAC2 / FT812 port (640x480)
Release v041 — 2026-05-26
========================================================================

ФАЙЛЫ ДЛЯ ЗАПУСКА (всё необходимое):
  ZUMA_VD2.SPG   — игра (SPG для Wild Commander, TS-Conf)
  ZUMALVL.PAK    — пак уровней (22 борда: фон/палитра/трек/превью/титул)

КАК ЗАПУСТИТЬ:
  Платформа: ZX Evolution / TS-Conf (FPGA) + VDAC2 (FT812), либо эмулятор
  Unreal Speccy (x64) с включённым FT812.
  1. Скопировать оба файла в каталог Wild Commander:
        /Games/Zuma Deluxe VDAC2/ZUMA_VD2.SPG
        /Games/Zuma Deluxe VDAC2/ZUMALVL.PAK
     (на FAT32-разделе SD-карты / в wc.img).
  2. Запустить Wild Commander, выбрать "Zuma Deluxe VDAC2".
  ВАЖНО: ZUMA_VD2.SPG и ZUMALVL.PAK должны лежать вместе — игра грузит
  фон/трек уровня из PAK своим FAT32-драйвером (CMD17) в рантайме.

ЧТО В ЭТОЙ ВЕРСИИ (v041):
  - Верхние уровни (L04/07/16/17/18/20-22) грузятся: трек разбит на 2
    страницы (#06+#0F) — длинные треки больше не отвергаются.
  - Параметры уровней из таблицы подключены в геймплей: число цветов
    шаров, скорость цепи, lead-in (стартовое заполнение), gauge до
    отсечения хвоста — всё per-level/сложность.
  - Прогресс-бар нормирован к реальному порогу уровня.
  - Счёт adventure переносится между уровнями (накопительный).
  - Win-state: "LEVEL DONE" со статистикой + OK -> fade-out -> след.
    уровень с Intro-анимацией.
  - Интро: реальный номер уровня "LEVEL X-X" (2x шрифт) + название,
    выравнивание по правому краю; сложность в номере.

Сборка: sjasmplus + spgbld. Исходники: Source/ASM, Source/OTHER.
