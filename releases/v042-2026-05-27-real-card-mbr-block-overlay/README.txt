Zuma Deluxe — VDAC2 / FT812 port (640x480)
Release v042 — 2026-05-27
========================================================================

ФАЙЛЫ ДЛЯ ЗАПУСКА (всё необходимое):
  ZUMA_VD2.SPG   — игра (SPG для Wild Commander, TS-Conf)
  ZUMALVL.PAK    — пак уровней (22 борда: фон/палитра/трек/превью/титул)

КАК ЗАПУСТИТЬ:
  Платформа: ZX Evolution / TS-Conf (FPGA) + VDAC2 (FT812), либо эмулятор
  Unreal Speccy (x64) с включённым FT812.
  1. Скопировать оба файла в каталог на FAT32-разделе SD-карты (или в
     wc.img). Папка теперь МОЖЕТ быть любой — игра ищет ZUMALVL.PAK по
     имени и размеру рекурсивно по всей карте (см. ниже). Удобно по-прежнему
     класть в /Games/Zuma Deluxe VDAC2/.
  2. Запустить Wild Commander, выбрать SPG.
  ВАЖНО: ZUMA_VD2.SPG и ZUMALVL.PAK должны лежать на одной карте — игра
  грузит фон/трек/превью уровня из PAK своим FAT32-драйвером в рантайме.

ЧТО В ЭТОЙ ВЕРСИИ (v042) — РАБОТАЕТ НА РЕАЛЬНОЙ SD-КАРТЕ:
  - Загрузка PAK с реальной 32GB SDHC-карты: добавлены ОПОЗНАНИЕ MBR-РАЗДЕЛА
    (BPB по началу раздела, все LBA со смещением раздела) и БЛОЧНАЯ
    АДРЕСАЦИЯ SDHC (автоопределение пробой; Unreal-суперфлоппи остаётся
    байтовым). Выровнено с FAT32-логикой плагина ChkDsk, который читает эту
    карту.
  - Поиск ZUMALVL.PAK по ИМЕНИ + РАЗМЕРУ рекурсивно по всему дереву каталогов
    — пак может лежать в любой папке (фикс-путь /Games/... убран).
  - Поддержка СЕГМЕНТИРОВАННОГО (фрагментированного) PAK: при открытии
    строится таблица экстентов (runs) по FAT-цепочке; читается и непрерывный,
    и фрагментированный файл (кэш FAT-сектора).
  - FAT-загрузчик ВЫНЕСЕН из Core в overlay-страницу (slot 3, #40), мапимую
    только на время загрузки уровня ("загрузил уровень и спит") — Core
    освобождён (с ~5 КБ до ~2.5 КБ).
  - Экран "LOADING LEVELS..." на ПЕРВОМ (медленном) переходе меню -> выбор
    уровней (пока строится карта секторов); последующие входы из кэша —
    мгновенные, без надписи.

Сборка: sjasmplus + spgbld (build_wc_img.cmd). Исходники: Source/ASM,
Source/OTHER. Карта памяти: Docs/memory_map_vdac2.md.
