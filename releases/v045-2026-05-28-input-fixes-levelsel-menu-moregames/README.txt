Zuma Deluxe VDAC2 / FT812 — опорная v045 (2026-05-28, host + REAL-HW verified)
================================================================================

Запуск: положить ZUMA_VD2.SPG + ZUMALVL.PAK в /Games/Zuma Deluxe VDAC2/ на SD/образе
Wild Commander (TS-Conf), запустить SPG. Уровни грузятся из PAK в рантайме.

В этой ревизии — папка Source/ с полными исходниками (ASM + Python build/pack/harness),
build.cmd / build_wc_img.cmd / spgbld_vdac2.ini для воспроизведения сборки.

ГЛАВНОЕ В ЭТОЙ РЕВИЗИИ — доводка ГЛОБАЛЬНОГО управления с клавиатуры (поверх v044)
--------------------------------------------------------------------------------
Тема та же, что и в v044 («или глобально работает, или глобально глюк»): весь ввод
идёт через резидентный Source/ASM/Input.asm. v045 закрывает три бага, найденные на
железе, + аудит «нет ли ввода в обход Input.asm» + чистку мёртвых файлов.

1. ВЫБОР УРОВНЯ — Вверх/Вниз были ПЕРЕПУТАНЫ. Бейджи сложности идут сверху вниз
   Sun God(3) / Jaguar(2) / Eagle(1) / Rabbit(0) (Y = 30 / 83 / 131 / 180), а клавиши
   двигали подсветку в противоположную сторону экрана. Теперь Вверх = к ВЕРХНЕМУ
   бейджу (CurrentDifficulty++, clamp 3 = Sun God), Вниз = к НИЖНЕМУ (CurrentDifficulty--,
   clamp 0 = Rabbit). Файл LevelSelect.asm (LevelSelectKeyboard).

2. ГЛАВНОЕ МЕНЮ — убраны Влево/Вправо из навигации (по просьбе юзера). Кнопки
   Adventure→More→Quit теперь ходят ТОЛЬКО по Вверх/Вниз; Влево/Вправо в этом меню
   не участвуют. Файл MenuMain.asm (MenuKeyboardNav).

3. MORE GAMES — выход в главное меню переделан. Был баг: выходило только по ESC, а по
   «глобальному огню» — нет.
   ПРИЧИНА: выход использовал Input_Fire = огонь-клавиши ИЛИ мышь-ЛКМ ОДНИМ сигналом.
   На этом стенде ЛКМ/Kempston-биты мыши порой читаются «нажато» ПОСТОЯННО (фантом —
   см. Frog.asm) → объединённый сигнал залипает в NZ → у клавиатурного огня НИКОГДА
   нет фронта → выходил только ESC.
   ФИКС: три НЕЗАВИСИМЫХ фронт-детектора (Input_EdgeZ) —
     - огонь-КЛАВИША: Space | Enter | Kempston-Fire (Input_FireKey, БЕЗ ЛКМ);
     - ЛКМ: Input_MouseLMB (изолированно — залипшая ЛКМ больше не блокирует огонь);
     - ESC: Input_Esc.
   Выход по фронту ЛЮБОГО из трёх. *Prev primed=1 на входе сцены гасят перенос нажатия
   из меню (нужен свежий «отпустить → нажать»). Файл MoreGamesSlot0.asm.

АУДИТ «ввод в обход Input.asm»
-----------------------------
В ассемблируемом коде ОБХОДОВ НЕТ. Прямые чтения только: RTC через Mr.Gluk (#EFF7/
#DFF7/#BFF7) в VDC.asm — это ЧАСЫ, не ввод (из-за них Input_Scan каждый кадр re-enable'ит
#EFF7); мышь через Input.Mouse.KeyState/PositionX/Y — отдельный легитимный путь, дублирует
клавиатуру; IN A,(STATUS) в Init_Video — видеостатус. Битовые AND #1F в MainLoop/ts-dos —
маски, не порт. Реальные обходы (#7FFE, #1F, прямой Kempston) были только в МЁРТВЫХ
бэкапах MainLoop_.asm и zuma_new_spg.asm — они НЕ в сборке и УДАЛЕНЫ в v045.

Поправлен устаревший комментарий про port #7FFE в shared_render.asm (Frog_FireKeyboard
давно идёт через глобальный Input_FireKey, порт напрямую не читается).

КОНТРАКТ ввода (без изменений с v044): Input_Init раз на старте; Input_Scan РОВНО раз/
кадр в КАЖДОЙ сцене; опросы Input_Up/Down/Left/Right/Esc/FireKey/Fire (NZ = активно);
Input_EdgeZ — детектор фронта для навигации. Раскладка: Вверх=↑|Q|Kemp, Вниз=↓|A|Kemp,
Влево=←|O|Kemp, Вправо=→|P|Kemp, Огонь=Space|Enter|Kemp|ЛКМ.

Локальные харнессы (карта памяти, загрузчики меню/выбора-уровня/More-Games, меню-инфлейт)
— все PASS. sjasmplus 0 ошибок.

ПРЕДЫДУЩАЯ ОПОРНАЯ: v044 (единый глобальный модуль ввода Input.asm: PC-клавиатура PS/2
через Mr.Gluk + Kempston + мышь, навигация меню/выбора уровня с клавиатуры).
