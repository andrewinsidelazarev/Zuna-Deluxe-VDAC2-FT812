Purpose
-------
Reference snapshot after the multi-GAP PULL jitter fix.

Fix Summary
-----------
VDC_GapJunctionUpdate no longer allows PULL to cross an already open
front-side marker gap. If another marker gap exists before the left edge of
the current gap run, the current gap closes as CATCH-UP instead: the front
segment stays fixed and the rear segment catches up.

Physical rear recoil on PULL merge is disabled. The merge click and pull-speed
reset remain, but no extra rear-segment micro-shift is applied.
