База: v093-2026-07-02-explodeframe-gate-reference.

Основные изменения после v093:

1. TRANSFORM-LUT для PALETTED ball matrix
   - Source/OTHER/make_chain_matrix_lut.py генерирует
     Graphics/Converted/chain_matrix_lut_l19_51_16.bin.
   - Source/ASM/MainLoop.asm переключён с runtime-команд FT812
     LOADIDENTITY/TRANSLATE/ROTATE/TRANSLATE/SETMATRIX на запись готовых
     BITMAP_TRANSFORM_A..F DL-слов из 16-bucket LUT.
   - Runtime test подтвердил совпадение CMD-буфера с LUT для 16 bucket'ов.

2. Lose state не стартует поверх активной match-3 анимации
   - Source/ASM/VDC.asm: VDC_LoseChainBusy учитывает VDC_ExplodeActive.
   - VDC_LoseHoldBeforeKillzone держит VDC_KzFrame=1, пока explode/gap
     реально busy, чтобы KZ warning не начинался поверх match-3.
   - ABSORB path через VDC_UpdateAbsorbOrRush анимирует pending explode/gap
     и не сдвигает цепь, пока match-3 не завершён.

3. Выстрелы при входе в kill-zone
   - Source/ASM/Bullet.asm: новый shot блокируется только на поздней фазе
     KZ warning, VDC_KzFrame>=9 или VDC2_KzFrame>=9.
   - При фактическом входе в ABSORB активная пуля/recoil гасятся.

4. Стабилизация цветов лягушки
   - Source/ASM/main.asm: Frog_RefilterCurrent теперь только sanitizer.
     Валидные Frog_BallColor и Frog_NextBallColor не меняются без выстрела:
     ни при переходе intro/preview -> PLAY, ни после cascade/match-3.
   - Refilter по live chain mask вызывается только для invalid/memory-corrupt
     значений (>= VDC_NUM_COLORS).
   - Source/ASM/Frog.asm: при реальном выстреле цвет пули остаётся тем,
     который был виден во рту; после успешного shot promote next -> current
     фильтруется через активную цепь, а новый next выбирается через
     Frog_NewNextColor.
